# AI usage

Mode: Operate. Extend the existing Shoji bar and its Material panel system; no replacement visual world. The user wants the reference Noctalia plugin's functionality with fewer interface elements.

## Direction contract

THESIS: Answer how much quota remains and when it resets without a dashboard. Never conflate account limits with public reset announcements.

OWN-WORLD: Inherit dynamic Material roles, Roboto Flex type, native controls, pill islands, 30px panel corners and existing panel motion. Remaining values carry emphasis; reset timing and details are secondary.

STORY: Glance at the bar, open the full account list, compare every quota window, disclose plan and reset-credit details only when needed. Errors retain a clearly marked last successful reading.

FIRST VIEWPORT: A compact remaining-quota ring around the AI symbol, with exact values in its tooltip and panel. Exhaustion, unknown percentage, loading and failure retain distinct symbols rather than misleading progress. Its panel retains a single title and remaining-quota key, icon-only refresh/settings actions, account chevrons, slim remaining bars and a clock symbol beside each compact countdown. The subdued public footer uses globe/calendar/forecast symbols. Update timestamps and full explanations live in accessible labels, tooltips and expanded details; errors remain explicit text.

FORM: Scoped extension of the incumbent native interface, not a new surface-world tournament; no seed is applicable. Horizontal and vertical placements preserve one data model and one session collector. The ring-only vertical island has equal top and bottom insets; optional status symbols belong to the same centered content group. Chinese and English copy follow locale.

SIGNATURE: A single click moves from one selected headline to every configured account; expanded detail does not replace the overview. Local countdowns do not request more network traffic. Synthetic preview data is explicitly marked Demo.
